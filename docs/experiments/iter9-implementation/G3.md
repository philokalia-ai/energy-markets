# Iteration-9 — G3 final gate: 43-zone vs 39-zone A/B

Gate G3 of the iter9 endogenization (AL / MK / ME / HR, 39 → 43 zones). Two
runs are recorded here:

- **iter9.0** (cv19 code, first cut): **NO-SHIP** — see the "iter9.0" section.
- **iter9.1** (cv21 code + two diagnosis fixes): **Gate 1 PASS, Gate 4 PASS,
  Gates 2/3 marginal FAIL → NO-SHIP** (this is the current record).

Method is identical across runs: both arms run through the SAME driver
(`ab_run.jl`) against the SAME read-only 43-zone DuckDB extract
(`START 2026-03-01 END 2026-07-21 AGEN_BACK_DAYS=90 AUX_BACK_DAYS=400` — a full
trailing year of flows/load so the cv19/cv21 `:v3` analogue pool is not
starved), `OPTIMIZER=highs`, `enrich_network=true passes=2 save_to_db=false`,
cv `:v3` flows on both arms. Windows: `apr` 2026-04-01..05, `jul`
2026-07-06..21, `mar` 2026-03-01..08 (29 days). Scoring: resolution-aware hourly
actuals from `entsoe.energy_prices` (iteration-4 standard), `score_ab.jl` +
`gate_check.jl`. Arm A = 39-zone control, B = 43-zone treatment.

## Pre-registered gates (unchanged, not weakened)

1. New zones clear: **corr ≥ 0.55** for MK/ME/HR, **≥ 0.40** for AL.
2. No existing (39) zone degrades by **> 0.03 corr** or **> 1.5 MAE**.
3. **HU control** must not degrade on July.
4. **SEE guard:** GR single-zone stays bit-identical.

### Gate 2 — 39-zone product protected: **FAIL** (marginal)

Worst per-window Δ (treatment − control):

| zone | window | Δcorr | ΔMAE | note |
|------|--------|-------|------|------|
| FR   | apr | **−0.165** | +1.5 | **degenerate day — see below** |
| NO1  | apr | −0.034 | +0.8 | marginal (5-day window) |
| SK   | apr | −0.033 | +1.3 | marginal |
| HU   | jul | −0.031 | **−3.4** | corr 0.001 past floor; **MAE improved** |
| SE4  | jul | −0.028 | **+1.8** | MAE |
| GR   | mar | −0.018 | **+3.0** | MAE (bias +1.7→+7.4) |

**FR April is a single-day artifact, not a fix regression.** Day-by-day, only
**2026-04-05** diverges (FR corr 0.93→0.37); the other four April days are
bit-identical or within 0.02. 04-05 is a **negative-price day** (FR actual
≈ −€0.2/MWh, spring structural oversupply) where the model floors positive
(sim ≈ +€50) — the "correlation" measures noise around a flat mis-level, and a
tiny solve difference flips it. Excluding this one degenerate hour-set, FR is
within tolerance in every window.

The genuine residual regressions are small and local: **GR March MAE +3.0** and
**SE4 July MAE +1.8** (two real MAE violations), plus marginal corr dips
(HU/NO1/SK all −0.031…−0.034, i.e. 0.001–0.004 past the 0.03 floor, mostly in
the 5-day April window). These are the coupled-footprint wobble cv18 documented,
now an order of magnitude smaller than iter9.0.

**DK1 — the iter9.0 red flag — is RESOLVED.** iter9.0 (cv19) had DK1 July
Δcorr **−0.074**; on cv21 (its own Viking boundary book) + these fixes it is
**−0.01**. Exactly the interaction the coordinator flagged ("measure, don't
assume") — cv21 absorbed it.

### Gate 3 — HU control (July): **FAIL** (marginal)

HU July: control corr 0.695 / MAE 72.4 → treatment corr 0.664 / MAE **69.0**
(**Δcorr −0.031, ΔMAE −3.4**). Fix 2 **improved HU's July MAE by 3.4** and
lifted its heavy under-pricing (bias −72.0 → −66.3); the corr dipped 0.031,
i.e. **0.001 past the floor**. HU March is flat-to-better (Δcorr −0.00, ΔMAE
−1.4). Net, HU is arguably better off, but the corr-based gate misses by a hair.

### Gate 4 — SEE guard: **PASS**

GR single-zone merit prices, this branch (cv21+iter9.1) vs cv21 main @`56a1d59`,
both on the extract, 2026-04-03: **bit-identical, 96/96 prices, 0 diffs**. The
iter9 changes (new profile registry keys, `"HR" in fp`-gated border logic) are
footprint-gated and inert for single-zone.

### Verdict & where it stands

Gate 1 (the primary "do the new zones price") is solved; Gate 4 holds; DK1 is
resolved. Gates 2/3 fail **marginally** — one degenerate FR negative-price day,
HU's corr 0.001 past the floor (with MAE improved), and two small MAE violations
(GR mar +3.0, SE4 jul +1.8). Per the pre-registered protocol (gates not
weakened) this is a **NO-SHIP: pushed, no PR.** The residual is small enough that
the ship/relax decision — and whether GR-March / SE4-July warrant one more
border-scoped lever, or HU's −0.031-corr / −3.4-MAE trade is acceptable — is the
coordinator's call. One concrete next lever: the GR March MAE +3.0 (bias +7.4)
tracks the AL/ME re-pricing lowering the SE coupled level GR imports from; a
GR-side scarcity/anchor tweak or a narrower AL/ME backstop-credit would target
it without touching the now-passing new zones.
