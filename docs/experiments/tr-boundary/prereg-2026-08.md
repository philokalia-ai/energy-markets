# TR/MK boundary book — preregistration (FROZEN 2026-08-05 ~21:30Z, before any scored run)

Owner mandate (2026-08-05): model Turkey properly — predict the collapses and

## Census that motivates (measured 2026-08-05, queries in the session record)

- **We have the counterparty's own data plane**: `epias.mcp` (hourly PTF in
  TL/USD/EUR, 2023→today, live), `epias.load_forecast`, `epias.actual_generation`
  by source, `epias.gas_reference_price` (daily GRP). No publication stamps in
  the tables (ETL gap, Phase-1 item) ⇒ every use below is **lagged ≥ 1 day**.
- **TR is administratively capped and currently very cheap in EUR**: share of
  hours ≥95% of the TL cap: 16.9% (2024), 24.9% (2025), 2.3% (2026); 2026 mean
  MCP €34. TR MCP runs BELOW its own CCGT SRMC (GRP/0.53+2) most of 2026
  (Apr: 18 vs 60) — hydro/RES-long, gas rarely marginal ⇒ **the honest anchor
  is trailing MCP**, not an SRMC construction.
- **Role split on BG's non-coupled borders (Jun–Aug 2026, net into BG)**:
  TR = import SOURCE (+38..+138 MW avg per 4h block, p10 ≈ 0 — rarely
  reverses); **MK = the export DRAIN** (−32..−142 avg, p10 −126..−435,
  strongest evenings). GR–TR: GR exports mildly (−3..−61 avg, p10 −100..−240).
  The :v3 fixed injection nets TR+MK and misses these signs both middays and
  evenings (the BG deep-dive's measured facts).
- **False-collapse census** (last 45 scored weather-L1 days; hours sim ≤ €20
  while settled ≥ €60): **BG 67 h / 26 d, GR 44 h / 19 d, RO 38/18, RS 9/4** —
  chronic and regional.

## Treatment (the third BoundaryBook instance)

- `TRMK_BG_BOOK` on BG: flow_codes `["TR","MK"]` (both stripped from
  `get_net_imports` + backstop); anchor **`:tr_trailing_mcp`** = mean
  `epias.mcp.price_eur` over [D−8, D−1) (lagged, day-cached, never cached on
  error; fallback when the feed is unreachable — e.g. the offline extract —
  0.55 × zone gas SRMC, the documented UA-style compromise); import ladder
  (TR sells) `[(1.0,0.5),(1.15,0.3),(1.35,0.2)]`; export ladder (TR/MK buy)
  `[(0.95,0.4),(0.80,0.35),(0.60,0.25)]`; capability `:p95_block`
  (trailing-366d p95 gross flow per 4h block, runtime); **firm export slice**
  (the MK drain: does not curtail on price) trailing-28d p10, cap-priced.
- `TR_GR_BOOK` on GR: flow_codes `["TR"]`; same anchor; import
  `[(1.0,0.5),(1.2,0.5)]`; export `[(0.95,0.5),(0.75,0.5)]`; firm slice on.
- Default **OFF** (opt-in `EUPHEMIA_ENABLE_TRMK=1`; profiles carry the book
  only when set). Activation/scoping (incl. the SEE byte-identity chain it
  would deliberately end) is a separate ship decision, not this experiment.

## Frozen evaluation

- **Arms**: baseline = the stored cv31 record (`multi_zone_eu`, code_version
  31, live Postgres), validity proven by a guard day re-cleared with the
  switch off matching to ≤1e-9 (the documented ULP class). Treatment = same
  code, `EUPHEMIA_ENABLE_TRMK=1`, announced inputs, same record path.
- **Set A**: 2026-07-08..2026-07-21 (14 days). **Set B**: 2026-07-22..
  2026-08-04, scored ONCE and only on an A-pass.
- **Primary gate (regime-conditional)**: false-collapse hours (sim ≤ €20 &
  settled ≥ €60) summed over BG+GR on Set A reduced **≥ 40%** vs baseline.
- **Guards**: ZERO new cap hours (≥ €2,999) in any zone vs baseline; per-zone
  envelope ΔMAE ≤ +3.0 / Δcorr ≥ −0.05 on all 39; BG and GR day-MAE not worse
  than baseline by > 0.5.
- **Secondary (report, no gate)**: sign-agreement of the TR/MK border stance
  (book-implied net vs realized) by 4h block; evening bias BG/GR.
- **Ex-ante audit**: anchor lag ≥ 1 day; capability/firm windows trailing;
  no same-day epias or flow reads anywhere in the treatment path.

## Disclosed limitations (declared before running)

- Daily-constant anchor (the BoundaryBook anchor is per-day); TR's hourly
  shape enters only through per-block capability/firm quantities. An hourly
  anchor from `epias.load_forecast` is a named refinement, not in this arm.
- MK has no fundamentals feed; its willingness rides the TR anchor inside the
  combined book (role-split via the directional ladders + firm slice).
- Expected partial closure of the midday gap: the census attributes part of
  the settled midday level to coupled GR/RO absorption and book-floor
  behaviour, out of scope here.
